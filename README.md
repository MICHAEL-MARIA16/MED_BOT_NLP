# 🐍 Anaconda Notebook Projects 📓

Welcome to the **Anaconda_codes** collection — a curated suite of Jupyter Notebooks focused on building and experimenting with natural language processing (NLP) bots. This repo is perfect for NLP enthusiasts, chatbot builders, and AI explorers who want hands-on experience with foundational and advanced bot logic.

---

## 🧠 Project Contents

### 🤖 `Med_Bot_Project.ipynb`
A conversational medical assistant trained with intent classification and symptom analysis. It simulates real-world medical Q&A and integrates basic diagnostic logic.

### ⚙️ `rulebased_bot.ipynb`
A minimal yet effective rules-based NLP chatbot. Demonstrates hardcoded pattern matching, conditional responses, and a lightweight decision engine.

### 🧪 `stemming_demo.ipynb`
An exploratory notebook showcasing **tokenization**, **stemming**, and basic text preprocessing techniques using `nltk`. Ideal for NLP beginners.

### 🩺 `medbot_task.ipynb`
Custom task-based version of the MedBot that includes user-defined intents and responses. Emphasizes extensibility.

### 💬 `medbot_BS16.ipynb`
A batch-specific version of the MedBot, tailored to a specific dataset or context (e.g., BS16 use case). Useful for benchmarking variations.

### 📍 `gptcode.ipynb`
Integrates GPT-style logic or experiments with transformer-based chatbot responses. A prototype for merging LLMs with traditional rules-based bots.

### 🧰 `sample_code.ipynb`
A sandbox for testing and prototyping smaller chunks of NLP code. Think of it as your scratchpad for logic experiments.
